Shot tables work too: a table with an "Action / visual" column and a "Dialogue and sound" column plays one row per clip. The action is the narrator, MARA: "…" is spoken by Mara, and SFX: / MUSIC: show as small sound cues.

Scene plates (optional): click Scene plates… and choose the folder that holds your images. Subfolders are searched too. Name each plate with the episode code, scene number and view letter, such as S01E01_S2_2A.png, and put the same episode code in the script's file name. To control when plates change, add a Markdown plan with the episode code and "plan" in its name, such as S01E01_plate_plan.md. It lists one view per line, such as - **2A** Wide shot (clips 2-01 … 2-04). Add a name after the range, as in (clips 2-05 … 2-09 (Mara)), to show that view while that character speaks. Without a plan, each scene's views are spread evenly across its clips. Plates follow a shot-table script with clip numbers such as 2-01 and headings such as ## Scene 2.

Lines that start with a name and a colon, or a name in capitals on its own line, are spoken by that character. Headings become scene markers. Everything else is the narrator. If something is picked up as a character that isn't one (say, "Camera"), switch it off in the Cast panel.
